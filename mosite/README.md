# MoSite for Home Assistant

MoSite provides a budget planner, stock trader, meal planner, and home and car
maintenance logbook. It listens on port 8000 and can be opened from the Home
Assistant sidebar.

Personal data is stored in this app's persistent `/config` folder. A new
installation starts with empty data. See the [project README](https://github.com/ae2mo/MoSite)
for setup and feature details.
